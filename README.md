## Щоденник розробника

### 25.09.2026 - Юніт 1: персонаж і рух

Під час виконання лабораторної роботи №2 я зміг створити сцену та додати до неї персонажа. Для створення рівня я налаштував Tilemap і намалював невелику підлогу за допомогою плиток. Також створив скрипт, за якого персонаж може ходити клавішами WASD та стрілками і підключив його до персонажа. Перевірив, як персонаж реагує на натискання різних клавіш та зробив запис. Розібрався з використанням Input Actions для отримання напрямку руху. Також зрозумів, навіщо використовується Time.deltaTime та як він впливає на швидкість руху персонажа. В результаті виконання лабораторної роботи №2 Мій персонаж може ходити по створеній підлозі за допомогою клавіш WASD та стрілок.
